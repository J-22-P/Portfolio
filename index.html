NOSION

Personal project · built solo

A productivity web app that brings tasks, personal finance and habits into one "Today" page, so you don't have to switch between three apps to see your day.

  • Designed and built the whole system: Next.js web app, NestJS API, PostgreSQL with Prisma, and a BullMQ worker for reminders
  • Quick capture that turns a plain sentence into a task, expense or habit
  • Email, Google and GitHub sign-in, GitHub issue sync, and a public API with Swagger docs
  • Installable PWA with offline support, light and dark themes, Thai and English
  • Unit, integration and end-to-end tests, with CI/CD on GitHub Actions and deploys to Vercel

Company project · full-stack, team · since Apr 2026

A suite of web applications that helps importers, exporters and customs brokers prepare, check and submit customs and trade documents, split into frontend and backend microservices.
